# Гардеробная

Личный сайт-гардероб для хранения фотографий вещей и составления образов. Результат подбора включает коллаж из фото выбранных вещей, который можно скачать как PNG.

## Файлы проекта

- `index.html` — страница сайта.
- `styles.css` — оформление и адаптация для телефона.
- `app.js` — коробки, загрузка фото, корзина и подбор образов.

## Запуск

Откройте `index.html` в браузере. Добавленные вещи, подписи и коробки сохраняются в локальном хранилище этого браузера.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите в корень репозитория `index.html`, `styles.css`, `app.js` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе сборки выберите публикацию из ветки `main` и папки `/ (root)`, затем нажмите **Save**.
5. После публикации сайт будет доступен по адресу GitHub Pages вашего репозитория.

Фото гардероба не добавляются в репозиторий: сайт хранит их в браузере на устройстве пользователя.
